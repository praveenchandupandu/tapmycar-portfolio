\# TapMyCar - Privacy-First Vehicle Contact Platform



\*\*Self-Directed Learning Project\*\* | Mar 2026 – Present



\## Overview

Complete SaaS platform connecting vehicle owners with service inquiries using NFC/QR stickers and privacy-first masked calling via Twilio.



\## What I Built



\### Database Architecture

\- Designed 30-table normalized PostgreSQL schema

\- Event-driven logging system for analytics

\- Query optimization through strategic indexing



\### Analytics System

\- Built event-logging infrastructure

\- SQL queries calculating DAU, activation rate, retention cohorts, churn rate

\- Discovered: First-call completion = #1 retention driver



\### Risk Modeling

\- K-means clustering on 12 behavioral/verification features

\- Segmented users into risk tiers

\- Tiers map to pricing strategy ($9.99-$24.99)



\### A/B Testing \& Statistics

\- Designed A/B tests with power analysis

\- Hypothesis testing on verification methods (SMS vs Email)

\- T-tests for statistical significance



\### Integration \& Deployment

\- Stripe: Payment processing

\- Twilio: Masked call routing (200+ calls)

\- Firebase: Real-time push notifications

\- Resend: Transactional email

\- Vercel: Serverless deployment

\- Supabase: PostgreSQL database
